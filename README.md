# CodeAlpha Internship Projects

This repository contains the frontend projects completed during my **CodeAlpha Web Development Internship**. Each project is built using **HTML, CSS, and JavaScript** and demonstrates different aspects of frontend web development.

## 📂 Projects

### 1. 🖼️ Image Gallery

An interactive image gallery that allows users to view and explore images in a visually appealing interface.

**Features:**

* Responsive image gallery
* Image lightbox view
* Next and previous navigation
* Keyboard navigation support
* Clean and interactive user interface

📁 **Folder:** `Task-1-Image-Gallery`

---

### 2. 🎵 Music Library

A web-based music library interface designed to organize and display music content.

**Features:**

* Organized music library interface
* User-friendly design
* Interactive frontend functionality
* Responsive layout

📁 **Folder:** `Task-2-Music-Library`

---

### 3. 💼 Personal Portfolio

A personal portfolio website created to showcase my profile, skills, and work.

**Features:**

* Personal introduction
* Skills and technology showcase
* Project/work sections
* Responsive design
* Clean and modern user interface

📁 **Folder:** `Task-3-Portfolio`

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run the Projects

1. Clone this repository:

```bash
git clone https://github.com/mahi03052003/codealpha_tasks.git
```

2. Open the project folder.

3. Navigate to any project folder.

4. Open the respective HTML file in your browser.

For example:

```text
Task-1-Image-Gallery/imagegallery.html
Task-2-Music-Library/musiclibrary.html
Task-3-Portfolio/portfolio.html
```
